## Como editar
- `config.js`: nome, contatos, texto "sobre", ferramentas e o link do **Publicar na Web** do Power BI (`relatorio`).
- `casos.js`: os cases, em português (`pt`) e inglês (`en`).
- `img/`: prints dos painéis. Para atualizar um print, substitua o arquivo mantendo o mesmo nome.

HTML, CSS e JavaScript puros, sem etapa de build: basta editar e fazer commit.
